# 推演机制核心改造讨论记录

> 记录时间：2026-06-15
> 背景：基于当前关系驱动推演模型的实现，讨论如何从"修补"走向"核心机制改造"

---

## 一、当前核心机制的本质

当前系统每回合的决策流程：

```
输入：当前局势 + 自身记忆 + 关系上下文
                ↓
        LLM 一次输出
                ↓
      action + relation_updates
```

每个 Agent 独立调用 LLM，互不感知同回合内其他 Agent 的行为。

**本质问题**：Agent 不是在博弈，而是在"写作文"。没有真正预测对方反应，没有一致的偏好和策略延续性。

---

## 二、触及核心的改造方向

### 方向 1：策略-行动双层决策

**目标**：让 Agent 行为有一致性，避免今天强硬明天突然投降。

**思路**：
- Agent 维护 `strategy` 字段，表示当前总体策略倾向（如"升级施压"/"缓和"/"观望"）
- 第一层 LLM 只判断是否需要调整策略
- 第二层 LLM 基于策略从动作空间中选择具体动作

**新增字段**：`Agent.strategy: str`

---

### 方向 2：信念-期望-行动循环（BDI 模型）

**目标**：让 Agent 对其他 Agent 形成预期，并根据实际结果更新。

**思路**：
- 每个 Agent 对其他 Agent 维护 `Belief`：
  - `expected_action`：我认为对方会做什么
  - `attitude_toward_me`：我认为对方对我的态度
  - `confidence`：信念确定程度
- 决策时基于信念选择行动
- 行动结果出来后更新信念

**新增字段**：`Agent.beliefs: dict[agent_id, Belief]`

这是所有机制的基础，优先级最高。

---

### 方向 3：博弈论机制（最佳响应）

**目标**：让 Agent 能算"哪种选择对我最好"。

**思路**：
- 为每个 Agent 定义收益函数（基于目标达成度、政权安全、经济利益等）
- 对每个候选动作，让 LLM 预测关键对手的最优回应
- 选择"我行动 → 对方回应 → 我收益"链条中收益最高的动作

**新增能力**：`AgentEngine._evaluate_best_response()`

---

### 方向 4：关系从结果变成驱动变量

**目标**：关系网络真正影响 Agent 决策。

**思路**：
- 决策 prompt 中增加"关系态势摘要"：谁支持我、谁反对我、谁摇摆
- 关系重大变化触发策略重评估
- 多个对手同时敌对时，Agent 应感知到"被包围"压力

**改动点**：`AgentEngine.build_relationships_context()`

---

### 方向 5：反事实推演（Fork）

**目标**：让用户能问"如果当时不这么做会怎样"。

**思路**：
- 在任意回合复制当前推演状态
- 修改一个关键行动或事件
- 继续推演并对比两个分支结局

**新增 API**：`POST /api/simulations/{id}/fork`

---

### 方向 6：可配置的世界模型本体

**目标**：从通用工具变成领域可配置工具。

**思路**：
- 用户可定义实体类型、关系类型、指标定义
- 例如"中东危机"可配置"教派"、"核能力"、"代理人"等维度

**改动点**：把 `AgentType`、关系标签、指标从硬编码改为 schema 配置。

---

### 方向 7：干预机制内生化为紧急响应

**目标**：注入事件后 Agent 立即应激反应，而不是等到下回合。

**思路**：
- `inject_event()` 后触发 `emergency_response_round()`
- 只让受影响 Agent 参与紧急决策
- 模拟真实危机中"事件突发 → 各方紧急应对"的动态

---

## 三、最小可行改造路径

如果现在要开始改，建议先做：

1. **给 Agent 增加 `strategy` 字段**
2. **每回合分两步调用 LLM**：
   - 第一步：判断是否需要调整策略
   - 第二步：基于策略选择具体行动
3. **决策 prompt 要求 LLM 在 reasoning 中说明"我认为 X 会怎么回应"**
4. **行动后更新 `strategy` 和简要信念**

这样改动量可控，但能显著提升行为一致性。

---

## 四、关键结论

> 核心不是"增加字段"和"多调用几次 LLM"，而是让 LLM 的每次调用都有明确的决策任务（预测/评估/选择），并用字段把决策结果持久化为 Agent 的内在状态。

没有信念-期望-行动循环，Agent 永远只是"每回合重新写作文"。
